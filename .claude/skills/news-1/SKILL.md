# news-1: 医療ニュースの収集と要約

医療・ヘルスケア分野の最新ニュースを集め、要約して会話に表示する。

## ルール

- **ファイルに保存しない。** Write・Edit・Bash でのファイル出力は使わず、結果は回答本文にだけ書く。
- **最大10件。** 信頼できる記事が10件に満たなければ、見つかった件数だけ表示する。数合わせはしない。
- **すべての項目に出典URLを付ける。** 実際に検索結果やページで確認したURLだけを使い、URLを推測や捏造で作らない。
- **新しさを優先する。** 原則として直近1週間以内の記事を選ぶ。日付が確認できない記事は避けるか、日付不明と明記する。
- 引数でテーマ（例: 「がん」「AI診断」「日本」）が指定されたら、そのテーマに絞る。

## 手順

1. WebSearch（ToolSearch で `select:WebSearch` を読み込んでから使う）で、複数の観点から検索を同じターンにまとめて投げる。例:
   - 「医療 ニュース 最新」「厚生労働省 発表」
   - "medical news this week", "FDA approval", "clinical trial results", "WHO health news"
   - 結果が薄い・古い場合は `mode: "extended"` で再検索する。
2. 必要に応じて WebFetch で記事本文を確認し、日付・要点を検証する。
3. 同じ話題の重複記事は1件にまとめ、公的機関・主要報道機関・学術誌など信頼性の高い出典を優先する。
4. 新しい順に最大10件を選び、下の形式で表示する。

## 出力形式

```
## 医療ニュース（YYYY-MM-DD 時点）

### 1. 見出し
- 日付: YYYY-MM-DD ／ 発信元: 媒体名
- 要約: 2〜3文で、何が起きたか・誰に関係するか・なぜ重要か。
- 出典: https://...

### 2. ...
```

最後に、件数と「医療上の判断は医師など専門家に相談してください」という一文を添える。
