# news-3: 日本の医療情報改革ニュースの収集と要約（出典照合つき）

日本政府が進める医療情報改革の最新ニュースを集め、出典ページの本文で確認した内容だけで要約して会話に表示する。

## 対象

政府・内閣府・厚生労働省・デジタル庁などが主導する、次のような取り組み:

- 医療DX推進本部・医療DX工程表
- マイナ保険証（マイナンバーカードの健康保険証利用）、資格確認書、オンライン資格確認
- 全国医療情報プラットフォーム、電子カルテ情報共有サービス、標準型電子カルテ
- 電子処方箋
- 診療報酬改定DX、共通算定モジュール
- 医療等情報の二次利用、次世代医療基盤法、仮名化情報、医療等ID
- 医療情報の標準規格（HL7 FHIR、厚労省標準規格、FHIR記述仕様・記録条件仕様など）
- PHR（パーソナルヘルスレコード）、自治体の予防接種・母子保健・介護情報のデジタル化
- 社会保険診療報酬支払基金の改組など、関連する法改正や制度変更

医療機関や企業の個別製品の宣伝は対象外。政府の施策との関係が明確な記事だけを選ぶ。

## ルール

- **結果をファイルに保存しない。** 結果は回答本文にだけ書く。出典ページの原文を読むための一時ファイルは、作業用フォルダ（scratchpad があればそこ）にだけ置いてよい。
- **最大10件。** 信頼できる記事が10件に満たなければ、見つかった件数だけ表示する。数合わせはしない。
- **すべての項目に出典URLを付ける。** 実際に検索結果やページで確認したURLだけを使い、URLを推測や捏造で作らない。
- **新しさを優先する。** 原則として直近2週間以内の記事を選ぶ。足りなければ直近1か月まで広げ、その旨を明記する。日付が確認できない記事は避けるか、日付不明と明記する。
- **一次情報を優先する。** 官公庁の発表（mhlw.go.jp、digital.go.jp、cao.go.jp、kantei.go.jp など）を最優先し、次に主要報道機関・業界専門メディアを使う。報道を引用する場合、一次情報も見つかればあわせて載せる。
- 引数でテーマ（例: 「マイナ保険証」「電子カルテ」「二次利用」）が指定されたら、そのテーマに絞る。

## 出典との照合ルール

- **要約は出典ページの本文で読んだことだけで書く。** WebSearch の回答文や WebFetch の要約は、記事を探す手がかりにだけ使う。日付・数字・発言・対象・条件は本文で確かめ、確かめられないものは書かないか「未確認」と書く。
- **発信元・指標名・単位・会議名は、ページの表記どおりに書く。** 推測で名前を補わない。
- **かぎかっこの中は原文どおり。** 省くときは「…」を入れる。言い換えるならかぎかっこを使わない。
- **文末の強さを変えない。** 「目指す」「見通し」「予定」「とされる」を「〜する」「〜かかる見込み」などに変えない。
- **条件・対象を落とさない。** 「〜の場合」「〜のうち」「〜向け」などの限定や、記事の想定読者が限られていること（例: 歯科医院向け）を残す。出典が一部だけを取り上げている場合（例: 「介護・事業者に関わるもの」）は、全体のように書かない。
- **出典にない解釈を足さない。** 影響や因果関係は、出典に書かれている場合だけ書く。
- **日付の種類を区別する。** 掲載日・発表日・開催日・施行日を混同しない。ページ内の更新履歴も確認し、日付が食い違えば両方を示す。
- **会員限定などで全文を読めない場合**は、読めた範囲だけで書き、見出しだけにある表現を本文の内容として扱わない。

## 手順

1. WebSearch（ToolSearch で `select:WebSearch,WebFetch` を読み込んでから使う）で、複数の観点から検索を同じターンにまとめて投げ、候補記事を集める。検索語には現在の年月を入れる。例:
   - 「医療DX 最新 YYYY年MM月」「医療DX推進本部」
   - 「マイナ保険証 厚生労働省 発表」「電子カルテ情報共有サービス」「電子処方箋 普及」
   - 「デジタル庁 医療 発表」「医療情報 二次利用 法改正」「全国医療情報プラットフォーム」
   - 「FHIR 厚生労働省」「HL7 FHIR 記述仕様」「医療情報 標準規格 厚労省」
   - 結果が薄い・古い場合は `mode: "extended"` で再検索する。
   - 厚労省の新着情報（https://www.mhlw.go.jp/stf/new-info/index.html）、デジタル庁のニュース（https://www.digital.go.jp/news）も確認する。
2. 選んだ記事のページを Bash の `curl -sSL` で取得し、HTML をテキストにして本文を読む。curl で取れない場合だけ WebFetch を使い、「本文の該当箇所をそのまま引用して」と頼む。
3. 同じ話題の重複記事は1件にまとめる。
4. 要約を書いたら、表示する前に一文ずつ本文と照らし合わせ、合わない記述は直すか消す。
5. 新しい順に最大10件を、下の形式で表示する。

## 出力形式

```
## 日本の医療情報改革ニュース（YYYY-MM-DD 時点）

### 1. 見出し
- 日付: YYYY-MM-DD（掲載日・開催日など種類も書く）／ 発信元: ページの表記どおりの名前
- 分野: 例）マイナ保険証、電子カルテ、標準規格（FHIR）、二次利用
- 要約: 2〜3文で、何が決まった・発表されたか、出典に書かれている影響や今後の予定。
- 確認範囲: 全文確認 ／ 冒頭のみ確認（会員限定）／ 一次情報未確認（報道のみ） のいずれか
- 出典: https://...

### 2. ...
```

最後に、件数を書き、確認できなかった点（一次情報が見つからなかった項目や、対象期間を広げたことなど）があれば短く添える。
